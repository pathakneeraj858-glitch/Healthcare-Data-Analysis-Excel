# 🏥 Hospital Overall Dashboard | Excel

## 📌 Project Overview
This project presents an interactive Hospital Overall Dashboard developed using Microsoft Excel and Power Pivot. It provides a comprehensive overview of hospital data through KPI tracking, data visualization, and interactive analysis to support data-driven decision-making.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power Pivot
- Pivot Tables & Pivot Charts
- Data Visualization
- KPI Analysis

## 📊 Dashboard Highlights
- Hospital Performance Overview
- Key Performance Indicator (KPI) Monitoring
- Interactive Data Filtering
- Healthcare Data Analysis
- Data-Driven Insights
- Visual Representation of Hospital Metrics

## 🎯 Project Objective
The objective of this project is to transform healthcare data into meaningful insights using Excel, enabling better monitoring of hospital performance, understanding key metrics, and supporting informed decision-making through interactive visualizations.
